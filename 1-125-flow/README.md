# Crypto Ranks (순위 구간별 코인 비교)

시가총액 순위 구간에 속한 코인들을 현재 차트(호스트 차트) 위에 한꺼번에 겹쳐 그리는 TradingView 지표입니다. 모든 코인 선은 화면 왼쪽 끝 봉의 호스트 종가에서 출발하므로, 화면에 보이는 구간 동안 어느 코인이 호스트보다 더 오르고 덜 올랐는지 바로 비교할 수 있습니다.

| 스크립트 | 차트 범례에 표시되는 이름 | 원본 순위 | 코인 수 | 라벨 기본값 | 순위표 기본 위치 |
|---|---|---|---|---|---|
| [`crypto_ranks_1_10.pine`](crypto_ranks_1_10.pine) | `1-10위 · 8개` | 1~10위 | 8 | 켜짐 | 위쪽 가운데 |
| [`crypto_ranks_11_50.pine`](crypto_ranks_11_50.pine) | `11-50위 · 32개` | 11~50위 | 32 | 꺼짐 | 아래쪽 가운데 |
| [`crypto_ranks_51_100.pine`](crypto_ranks_51_100.pine) | `51-100위 · 40개` | 51~100위 | 40 | 꺼짐 | 왼쪽 아래 |
| [`crypto_ranks_101_125.pine`](crypto_ranks_101_125.pine) | `101-125위 · 22개` | 101~125위 | 22 | 꺼짐 | 오른쪽 아래 |

네 스크립트는 모두 Pine Script v6로 작성되어 있습니다. 코인 목록, 색상, 위 표의 기본값만 다르고 계산 코드는 같습니다. 순위표 기본 위치를 스크립트마다 다르게 정해 두었으므로, 지표 여러 개를 한 차트에 올려도 순위표끼리 겹칠 가능성이 낮습니다. 다만 차트 창의 높이가 낮으면 겹칠 수 있으니, 그럴 때는 설정에서 위치를 바꾸면 됩니다.

## 계산 방식

1. **기준 가격**을 정합니다.
   - 화면 왼쪽 끝 봉(`chart.left_visible_bar_time`)에서 각 코인의 종가를 기준 가격으로 삼고, 같은 봉의 호스트 종가를 출발점으로 삼습니다.
2. **등락률**을 계산합니다.
   - `등락률 = (코인 종가 ÷ 기준 가격 − 1) × 100`
3. **호스트 가격 단위로 변환**해서 그립니다.
   - `선의 값 = 출발점 호스트 종가 × (1 + 등락률 ÷ 100)`
   - 그래서 모든 선이 호스트 캔들과 같은 가격 축을 공유합니다.
4. **화면 오른쪽 끝 봉의 값**을 라벨과 순위표에 표시합니다.
   - 차트를 스크롤하거나 확대·축소하면 지표 전체가 다시 계산되므로, 표시되는 등락률은 언제나 지금 화면에 보이는 구간을 기준으로 합니다.

### 화면 중간에 데이터가 시작되는 코인

상장한 지 얼마 되지 않은 코인은 화면 왼쪽 끝 봉에 아직 가격 데이터가 없을 수 있습니다. 이런 코인은 데이터가 처음 나타나는 봉을 기준으로 삼고, 그 봉의 호스트 종가에서 선을 시작합니다. 이 코인의 등락률은 다른 코인과 기간이 다르므로 다음과 같이 따로 표시합니다.

- 라벨: `PONS 12.3% (since 2026-07-17)`
- 순위표: 코인 이름 뒤에 `*`를 붙입니다. (예: `PONS*`) 마우스를 올리면 시작일이 툴팁으로 표시됩니다.
- 툴팁: `change (since 2026-07-17)`

`since` 뒤의 시작 시점은 차트의 시간 단위에 따라 다음과 같이 표시합니다.

| 차트 시간 단위 | 표시 형식 | 기준 |
|---|---|---|
| 분봉, 시간봉 | `2026-07-17 16:00 UTC` | 봉이 시작한 시각을 거래소 시간대로 표시하고, 시간대 이름을 함께 적습니다. |
| 일봉(1D) | `2026-07-17` | 그 봉이 속한 거래일입니다. CME 선물이나 외환처럼 전날 저녁에 거래가 시작되는 종목도 차트의 날짜 축과 같은 날짜가 나옵니다. |
| 2일봉 이상, 주봉, 월봉 | `2026-07-13` | 봉이 시작한 날짜입니다. |

Pine 스크립트는 차트에 설정한 표시 시간대를 읽을 수 없습니다. 그래서 분봉과 시간봉에서는 시간대 이름(예: `UTC`)을 함께 적어서, 차트를 한국 시간으로 보고 있을 때도 혼동하지 않도록 했습니다.

## 표시 요소

| 요소 | 내용 |
|---|---|
| 선 | 코인마다 색이 다른 선을 하나씩 그립니다. 상태 표시줄과 가격 축에는 값을 표시하지 않습니다(`display.pane`). |
| 라벨 | 화면 오른쪽 끝 봉 위치에 `티커 등락률%`을 코인 색 바탕으로 표시합니다. 글자색은 바탕색과의 대비가 더 큰 쪽(검은색 또는 흰색)으로 자동 선택합니다. 코인이 많은 11-50위, 51-100위, 101-125위 지표에서는 라벨이 서로 겹치므로 기본으로 꺼 두었습니다. |
| 순위표 | 모든 코인을 등락률이 높은 순서로 정렬해서 표로 보여 줍니다. 코인 이름 칸은 선과 같은 색으로 칠하므로 범례 역할도 합니다. 코인이 20개를 넘으면 두 열로 나눠 표시합니다. 순위표를 위쪽에 두면, 차트 범례(종목 이름과 시가·고가·저가·종가)에 가려지지 않도록 맨 위에 빈 줄을 하나 둡니다. |
| 툴팁 | 라벨이나 순위표의 칸에 마우스를 올리면 실제로 요청한 심볼(예: `CRYPTO:ARBIUSD`), USD 가격, 등락률을 보여 줍니다. |

현재 시점이 화면에 보일 때는 라벨이 오른쪽 여백 쪽으로 그려지고, 과거 구간으로 스크롤했을 때는 가격 축에 가려지지 않도록 라벨이 차트 안쪽(왼쪽)으로 그려집니다.

## 데이터 출처

- 모든 코인은 TradingView의 `CRYPTO:` 지수 심볼(예: `CRYPTO:BTCUSD`)로 요청합니다.
- 같은 티커를 쓰는 다른 코인과 구분하려고 TradingView가 접미사를 붙인 심볼이 있습니다. 예를 들어 Arbitrum은 `CRYPTO:ARBUSD`가 아니라 `CRYPTO:ARBIUSD`이고, Lighter는 `CRYPTO:LITLUSD`입니다. (`CRYPTO:LITUSD`는 Litentry라는 다른 코인입니다.) 각 선의 실제 심볼은 지표 설정의 스타일 탭에 표시되는 선 이름에서 확인할 수 있습니다.
- 코인 목록은 2026-09-21에 저장한 TOP1000 순위 스냅샷을 기준으로 합니다. 순위가 바뀌어도 목록은 자동으로 갱신되지 않습니다.
- 스테이블코인, 금 담보 토큰, 그리고 PI·JST·FLR·NEXO·GNO·FF·SUN·GT는 제외했습니다. 그래서 순위 번호 중간에 빠진 번호가 있습니다.
- 2026-10-18에 확인한 결과, 네 스크립트에 들어 있는 102개 심볼은 모두 TradingView에 존재하고 실시간으로 시세가 갱신되고 있었습니다.

## 설정

| 입력 | 기본값 | 설명 |
|---|---|---|
| 코인 이름과 등락률 표시 | 스크립트마다 다름 | 선 끝의 라벨을 표시합니다. 맨 위 표의 "라벨 기본값"을 참고하세요. |
| 선 두께 | 1 | 1~4 |
| 등락률 순위표 표시 | 켜짐 | 정렬된 순위표를 표시합니다. |
| 순위표 위치 | 스크립트마다 다름 | 위 표의 "순위표 기본 위치"를 참고하세요. 차트 안의 9개 위치 중 8곳(정중앙 제외)을 고를 수 있습니다. |

## 알아 둘 점

- **요청 개수 제한:** Pine 스크립트 하나에서 쓸 수 있는 `request.*()` 호출은 40개까지입니다(Ultimate 요금제는 64개). `crypto_ranks_51_100.pine`은 이미 40개를 쓰고 있으므로, 이 파일에 코인을 더 추가하면 대부분의 요금제에서 실행 오류가 납니다.
- **가격 축:** 모든 선이 호스트와 같은 가격 축을 쓰기 때문에, 한 코인이 크게 오르거나 내리면 자동 축척이 넓어져서 캔들이 납작해질 수 있습니다. 가격 축을 오른쪽 클릭해서 로그 축척을 켜거나, 해당 코인의 선을 스타일 탭에서 끄면 됩니다.
- **라벨 겹침:** 라벨을 켜면 등락률이 비슷한 코인끼리 오른쪽 끝에서 라벨이 겹칩니다. 바탕이 불투명해서 맨 위 라벨은 읽을 수 있지만, 아래에 깔린 라벨은 가려집니다. 전체 값은 순위표에서 확인하세요.
- **하이킨 아시, 렌코 등 비표준 차트:** 출발점은 화면에 그려진 캔들의 종가(계산된 값)이고, 코인 선은 실제 종가로 계산합니다. 그래서 출발점에서는 선이 캔들에 맞지만, 이후에는 캔들과 조금씩 어긋날 수 있습니다. 등락률 값 자체는 정확합니다.

## 적용 방법

1. TradingView의 Pine Editor에 원하는 `.pine` 파일의 내용을 붙여 넣고 저장합니다.
2. 비교하고 싶은 차트(예: `BINANCE:BTCUSDT`)를 열고 지표를 추가합니다.
3. 이미 차트에 붙어 있는 이전 버전의 지표는 저장된 설정을 그대로 유지합니다. 그래서 라벨이 켜진 상태로 남아 있을 수 있습니다. 새 기본값을 쓰려면 지표 설정 창에서 **Defaults → Reset settings**를 누릅니다. 새로 추가된 입력(순위표 표시, 순위표 위치)은 처음부터 기본값으로 시작합니다.

## 변경 이력

### 2026-10-18: 저장소에 추가하고 리뷰에서 확인된 문제를 수정

업로드된 원본은 첫 번째 커밋에 그대로(줄바꿈만 LF로 변경) 보관했습니다. 이어서 여러 에이전트로 코드를 리뷰하고, 지적 사항마다 독립적인 검증자 두 명이 반박을 시도하게 했습니다. 그 과정을 통과해 확인된 문제를 다음과 같이 수정했습니다.

- **라벨이 겹쳐서 읽을 수 없음:** 22~40개의 라벨이 같은 x 위치에 그려져서 서로 겹쳤습니다. 51-100위 지표를 30일 구간으로 시뮬레이션했을 때 29개 라벨 중 28개가 겹쳤습니다. 등락률 순으로 정렬한 순위표를 추가했고, 코인이 22개 이상인 세 지표는 라벨을 기본으로 꺼 두었습니다.
- **늦게 상장한 코인의 출발점과 등락률이 틀림:** 화면 중간에 데이터가 시작되는 코인도 왼쪽 끝 봉의 호스트 종가에서 선이 시작되어서, 캔들과 크게 떨어진 위치에 그려졌습니다. 라벨에는 상장 이후 등락률을 "visible-range change"라고 표시했습니다. 이제 데이터가 시작되는 봉의 호스트 종가에서 선을 시작하고, `*`와 `since 날짜`로 표시합니다. 날짜는 차트의 시간 단위에 맞춰 표시합니다.
- **과거로 스크롤하면 라벨이 잘림:** 라벨이 화면 오른쪽 끝 봉에서 오른쪽으로 그려져서 가격 축 뒤로 숨었습니다. 과거 구간을 볼 때는 라벨을 안쪽으로 그립니다.
- **툴팁의 심볼이 실제 심볼과 다름:** 툴팁이 `CRYPTO:` 뒤에 짧은 티커를 붙여서 만들었기 때문에, 102개 중 26개는 실제로 요청한 심볼과 달랐습니다. 그중 4개(LIT, STX, STRK, PONS)는 다른 코인의 심볼과 같았습니다. 이제 `request.security`에 넘긴 심볼을 그대로 표시합니다.
- **같은 파일 안에서 구분되지 않는 색:** 모든 색의 채도와 명도가 같고 색상(hue)만 조금씩 달라서, 11-50위의 GRAM/SKY, 51-100위의 JUP/SEI처럼 사실상 같은 색으로 보이는 쌍이 있었습니다. 29개 코인의 색을 바꿔서, 같은 파일 안의 모든 색 쌍이 CIEDE2000 기준 5 이상 차이 나도록 했습니다.
- **실시간 봉마다 라벨이 쌓임:** 라벨을 지우지 않고 새로 만들었기 때문에, 화면을 고정해 둔 상태에서 새 봉이 생길 때마다 같은 라벨이 겹겹이 쌓였습니다. 이전 라벨을 지우고 새로 만들도록 바꿨습니다.
- **아주 싼 코인의 툴팁 가격이 부정확함:** 소수점 8자리에서 반올림해서 BTT(약 0.00000035달러)는 유효 숫자가 2개만 남았습니다. 0.001달러 미만인 코인은 소수점 12자리까지 표시합니다.
- **라벨 글자가 잘 보이지 않음:** 투명한 바탕에 코인 색으로 글자를 써서, 어두운 테마에서는 파란 계열, 밝은 테마에서는 노란·연두 계열 글자가 잘 보이지 않았습니다. 라벨 바탕을 코인 색으로 채우고, 글자색은 검은색과 흰색 중 대비가 큰 쪽으로 고릅니다. 102개 색 모두에서 대비가 4.6:1 이상입니다.

수정한 결과도 같은 방식으로 다시 검증했습니다. 그 과정에서 추가로 확인된 세 가지(코인이 많은 지표의 라벨 기본값, `since` 날짜가 하루 어긋나는 경우, 위쪽에 둔 순위표가 차트 범례에 가려지는 문제)도 함께 수정했습니다. 수정한 네 파일은 TradingView 컴파일러에서 오류와 경고 없이 컴파일됩니다.
