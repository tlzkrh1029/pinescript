# 1-125 Flow: 웹 대시보드 아이디어와 시안

시가총액 순위 1~125위 코인의 흐름을 한 화면에서 내려다보는 웹 대시보드("1-125 Flow")를 구상하면서 만든 시안과 아이디어를 기록합니다. 같은 폴더의 TradingView 지표([`../`](../))를 대체하려는 것이 아니라, 지표로는 보기 어려운 전체 흐름을 보여 주는 것이 목적입니다.

- 시안 캔버스: [1-125 Flow 시안](https://claude.ai/artifact/6UBqrYe2eka2TgJcYRu9yj) (비공개 링크입니다. 다른 사람에게 보여 주려면 캔버스의 Share 메뉴에서 공유해야 합니다.)
- 이 폴더의 `canvas/`에는 캔버스에 올린 원본 파일이 그대로 들어 있습니다. `.dc.html`은 캔버스 전용 형식이라 GitHub이나 브라우저에서 바로 열면 화면이 아니라 코드로 보입니다. 화면은 위 캔버스 링크에서 확인합니다.

## 출발점

기존 TradingView 지표는 15분봉이나 1시간봉 차트에서 12~24시간을 띄워 두고 단기 흐름을 실시간으로 보는 데 쓰였습니다. 기준 시각(화면 왼쪽 끝 봉)은 그때그때 바꿉니다. 이 화면에서 알고 싶은 것은 다음 네 가지입니다.

1. **강한 코인 순위:** 지금 BTC보다 강한 코인이 무엇이고 얼마나 강한지
2. **막 강해지는 코인:** 최근 몇십 분 사이에 치고 나가는 코인
3. **시장 분위기:** 알트코인 전체가 BTC보다 강한지 약한지
4. **선 모양 비교:** BTC 캔들 위에 겹친 선이 함께 움직이는지

지표 방식(코인 하나를 선 하나로 그리기)은 코인이 40개를 넘으면 선과 라벨이 엉켜서 읽기 어렵습니다. 그래서 코인 하나를 점이나 칸 하나로 표현하는 화면을 따로 구상했습니다.

## 1차 시안: 장기 흐름 (보류)

캔버스의 "1차 · 장기 흐름" 페이지에 있습니다. 데이터는 일봉(2026-10-28 종가)과 주간 순위 스냅숏입니다.

| 시안 | 파일 | 보여 주는 것 |
|---|---|---|
| ① 회전 그래프 | `Main.dc.html` | BTC 대비 상대강도(가로축)와 그 변화 속도(세로축)를 점으로 찍고, 최근 15일의 이동 경로를 꼬리로 그립니다. 주도·약화·부진·개선 네 구역으로 나뉩니다. |
| ② 히트맵 | `Heatmap.dc.html` | 102개 코인을 순위 구간별 타일로 묶습니다. 타일 크기는 시가총액의 제곱근, 색은 BTC 대비 등락률(1·7·30·90일)입니다. |
| ③ 순위 흐름 | `RankFlow.dc.html` | 14주(2026-07-26~10-25) 동안의 주간 순위를 선으로 잇고, 순위 구간 사이의 이동을 표로 정리합니다. |
| ④ 시장 폭 | `Breadth.dc.html` | 구간별로 최근 30일 동안 BTC보다 많이 오른 코인의 비율을 시계열로 그립니다. |

**보류한 이유:** 네 시안 모두 일·주 단위라서 몇 시간 단위의 단기 흐름을 볼 수 없었습니다. 기존 지표를 쓰는 목적과 맞지 않는다는 지적을 받아 2차 시안을 새로 만들었습니다. 사용 방식을 먼저 확인하지 않고 일봉 데이터를 기준으로 설계한 것이 원인이었습니다.

## 2차 시안: 단기 흐름

캔버스의 "2차 · 단기 흐름" 페이지에 있습니다. 데이터는 2026-10-29 21:45(한국 시간) 기준 Binance 현물 5분봉 스냅숏입니다. 모든 화면에서 기준 시각을 1·4·12·24시간 전으로 고를 수 있고, 기본값은 12시간 전입니다.

| 시안 | 파일 | 답하는 질문 | 보여 주는 것 |
|---|---|---|---|
| ① 순위·선 비교 | `Live.dc.html` | 1, 4 | 왼쪽은 기준 시각 이후 등락률 선 차트입니다. BTC는 굵은 선, 상위·하위 5개는 색 선, 나머지는 옅은 선으로 그립니다. 오른쪽은 BTC 대비 순위 목록이며, 행마다 작은 추이선과 "최근 1시간" 열이 있습니다. |
| ② 가속 | `Accel.dc.html` | 2 | 가로축은 기준 시각 이후 BTC 대비, 세로축은 최근 1시간 BTC 대비입니다. 이전에는 약했지만 최근 1시간에 강해진 "새로 강해짐" 구역을 가장 앞에 두었고, 최근 2시간의 이동 경로를 꼬리로 그립니다. |
| ③ 시장 분위기 | `Mood.dc.html` | 3 | 구간별로 BTC보다 강한 코인의 비율을 15분 간격으로 그립니다. "기준 시각 이후"와 "최근 1시간"을 전환할 수 있어서, 추세와 막 바뀌는 흐름을 나눠 볼 수 있습니다. |
| ④ 히트맵 | `ShortHeat.dc.html` | 1 | 1차 히트맵과 같은 배치를 15분·1시간·4시간·12시간·24시간 단위로 보여 줍니다. 색 단계 간격은 실제 분포에 맞춰 0.2~0.5%로 정했습니다. |

스냅숏 시점의 예: 12시간 전(09:45)부터 BTC보다 강한 코인은 81개 중 24개였고, 최근 1시간만 보면 81.5%가 BTC보다 강했습니다. 단기 분위기가 막 바뀌는 장면이 데이터에 잡혀 있습니다.

## TradingView 지표와의 역할 분담

두 가지를 함께 쓰기로 했습니다.

- **TradingView 지표:** 차트 위에서 선 모양을 직접 비교하고, 순위표로 호스트 대비·가속·강함 개수를 봅니다. TradingView의 `CRYPTO:` 지수를 쓰므로 102개 코인이 모두 들어갑니다. 자세한 내용은 [`../README.md`](../README.md)에 있습니다.
- **웹 대시보드:** 102개 코인 전체를 한 화면에서 순위, 가속, 분위기로 내려다봅니다. 흐름에서 눈에 띄는 코인을 고른 뒤, 지표에서 자세히 비교하는 순서로 씁니다.

## 실시간 연결 계획 (아직 시험하지 않음)

시안은 한 시점의 스냅숏입니다. 실제 화면에서는 claude.ai 페이지가 사용자의 Binance 커넥터를 불러서 1분마다 갱신하는 구조를 생각하고 있습니다.

- **등락률과 순위:** Binance의 rolling window ticker(`spot.ticker`)는 코인 100개까지의 "최근 N분/N시간 등락률"을 요청 한 번으로 돌려줍니다. N은 1분부터 7일까지 고를 수 있습니다.
- **선과 꼬리:** 추이선과 가속 꼬리는 코인마다 분봉을 받아야 해서, 1분마다 80여 번을 호출해야 합니다. 이 호출 빈도가 커넥터에서 가능한지는 아직 시험하지 않았습니다.
- **기준 시각 직접 지정:** 시안에서는 미리 계산한 기준만 동작합니다. 실제 화면에서는 원하는 시각을 고를 수 있게 만들 예정입니다.

## 폴더 구성과 데이터 다시 만들기

| 경로 | 내용 |
|---|---|
| `canvas/` | 캔버스 원본: 시안 8개(`.dc.html`)와 배치 파일(`canvas.json`) |
| `data/` | 시안에 쓴 데이터: 순위 구성, Binance 일봉·5분봉, 화면별로 계산한 `view_*.json`(1차)과 `short_*.json`(2차) |
| `data/cmc/` | CoinMarketCap 주간 스냅숏 14개를 정리한 JSON |
| `scripts/` | 데이터를 받고 계산한 Python 스크립트 |
| `SPEC.md`, `SPEC2.md` | 시안을 만든 에이전트에게 준 설계 지시서(1차, 2차)입니다. 영어로 썼습니다. |

모든 스크립트는 이 폴더(`web-mockups/`)에서 실행합니다. 계산 스크립트는 저장된 데이터만으로 같은 결과를 다시 만듭니다.

```bash
python3 scripts/prep.py            # data/view_*.json  (1차)
python3 scripts/prep_intraday.py   # data/short_*.json (2차)
```

데이터를 새로 받으려면 다음 순서로 실행합니다. 용량이 커서 저장소에 넣지 않은 두 가지 원본은 먼저 내려받아야 합니다. 하나는 Binance 심볼 목록(약 17MB)이고, 다른 하나는 CoinMarketCap 과거 스냅숏 HTML(주마다 약 670KB)입니다.

```bash
python3 scripts/scan_top.py data/tv_top.json      # TradingView 스크리너
python3 scripts/build_universe.py                 # data/universe.json
curl -o data/bn_exinfo.json "https://data-api.binance.vision/api/v3/exchangeInfo?permissions=SPOT"
python3 scripts/fetch_klines.py                   # data/klines_1d.json
python3 scripts/fetch_5m.py                       # data/klines_5m.json
# https://coinmarketcap.com/historical/YYYYMMDD/ 를 data/cmc/cmc_YYYYMMDD.html 로 저장한 뒤
python3 scripts/cmc_extract.py 20261025 20261018  # data/cmc/cmc_YYYYMMDD.json
```
