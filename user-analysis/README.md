# user-analysis

다른 TradingView 사용자가 만든 지표나 전략을 분석한 기록을 보관하는 폴더입니다. 원본 코드는 대부분 비공개이므로, 차트 스크린샷과 공개된 설명을 근거로 동작 방식을 역추적하고, 그 근거와 한계를 함께 기록합니다.

사용자마다 하위 폴더를 하나씩 두고, 폴더 안의 README에 분석 내용과 출처, 변경 이력을 기록합니다. 분석에 사용한 스크린샷은 각 폴더의 `images/`에 `YYYY-MM-DD-심볼-타임프레임-내용` 형식의 이름으로 저장합니다.

| 폴더 | 대상 | 설명 |
|---|---|---|
| [`cryptonewton`](cryptonewton/) | Razor Harmonics, Razor Divergence Hunter (Razor Alpha) | XABCD 하모닉 패턴과 오실레이터 다이버전스를 찾아 점수와 등급을 매기고, 진입가·손절가·목표가와 자체 성과표를 표시하는 판매용 지표입니다. 제작자가 X에 올린 스크린샷 10장을 바이낸스 4시간봉과 대조해 규칙을 역산했습니다. |
